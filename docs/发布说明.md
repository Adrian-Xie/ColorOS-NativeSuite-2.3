# ColorOS NativeSuite 2.3 公开测试

主功能为流体云相关特性及原厂配套、堆叠后台与桌面卡片。含部分原厂主题资源及桌面堆叠状态修复。通过开机挂载生效，固定框架仅缺失时部署，首次可能需两次重启。

已验证设备：OPPO A6k 5G PLT120，ColorOS 15.0.2.1005(CN01)。PLT120 / 15.0.2.1002 存在流体云设置页面退出反馈，未定位。ColorOS 16 未实测。

不保证完整 AI、所有流体云业务或主题模板。小布建议卡片添加仍失败，问屏、视频总结、票务日程与真实订单未完成验收。具体安装、功能边界、回退方式见仓库 README。

无固定机型 / 固件 / ColorOS 上限锁，无外部元模块依赖；保留完整性、XML、ABI、页大小、组件 SDK 与挂载条件检查。
