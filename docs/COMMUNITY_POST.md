为 OPPO 低端机 ColorOS 15 补全部分原生特性（2.3 正式版）

补全部分：原厂流体云相关开关与配套组件、堆叠后台、桌面卡片；另含部分原厂灵感主题资源。

构建方式：ChatGPT / OpenAI Codex 协助编写、调试与打包，第三方修改项目，非 OPPO 官方发布。

GitHub 链接：https://github.com/yifengxie0-ai/ColorOS-NativeSuite-2.3
下载：https://github.com/yifengxie0-ai/ColorOS-NativeSuite-2.3/releases/tag/v2.3

模块思路：按本机原配置修改指定特性，不额外开启全局高负载动画和模糊开关。通过原厂组件与开机挂载恢复部分功能，堆叠状态问题使用桌面专用 Hook 修复。

适用范围：主要面向 OPPO A6k 5G（PLT120）/ ColorOS 15。15.0.2.1002 有流体云设置页面退出反馈；ColorOS 16 和其他机型不保证兼容。不设固定版本上限不等于通用适配。

注意事项：
1. 用 KernelSU / KernelSU Next 安装。缺失时会部署 Zygisk Next 1.5.3 与 LSPosed Irena 2.0.0，并尝试自动启用桌面堆叠修复。首次部署可能需两次重启，ZIP 只需刷一次。自动配置失败时，在 LSPosed 启用修复、只勾选系统桌面后重启。
2. 已包含智慧决策服务、智慧数据增强等选用的原厂配套应用，无外部元模块依赖。不要重复刷原补全包、扩展包，勿随意覆盖系统组件。
3. 外卖、打车等流体云业务依赖应用接入、账号、权限和原厂云端，不保证所有场景均可用。小布建议卡片问题仍存在；完整 AI 功能、全部主题与锁屏组件不作保证。
4. 采用开机挂载，不永久改写只读系统分区。停用并重启可回退，建议保留备份及模块停用方式。
5. 本项目用于个人设备，不承诺维护或后续 Bug 修复，不接受 Bug 反馈。有需要可下载源码自行研究修改，第三方文件遵守各自许可。
