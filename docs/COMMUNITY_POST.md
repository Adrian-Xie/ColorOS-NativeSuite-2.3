为 OPPO 低端机 ColorOS 15 补全部分原生特性（2.3 公开测试版）

补全部分：原厂流体云相关开关与配套组件、堆叠后台、桌面卡片；另含部分原厂灵感主题资源。

构建方式：ChatGPT / Codex 协助编写、调试与打包，第三方修改项目，非 OPPO 官方发布。

GitHub 链接：https://github.com/yifengxie0-ai/ColorOS-NativeSuite-2.3

模块思路：按本机原配置修改指定特性，不额外开启全局高负载动画和模糊开关。通过原厂组件与开机挂载恢复部分功能，堆叠状态问题使用桌面专用 Hook 修复。未进行量化性能、耗电测试。

测试记录：
1. OPPO A6k 5G（PLT120），ColorOS 15.0.2.1005(CN01)：已验证安装、挂载、组件注册和堆叠切换。完整业务场景没有全部验收。
2. PLT120，ColorOS 15.0.2.1002：有流体云设置页面退出反馈，尚未定位。
3. ColorOS 16 和其他机型未实测；不设固定版本限制不等于保证兼容。

注意事项：
1. 使用 KernelSU / KernelSU Next 安装。整合包缺失时会安装 Zygisk Next 1.5.3 与 LSPosed Irena 2.0.0，并尝试自动启用桌面堆叠修复；首次安装框架可能需要两次重启，ZIP 只需刷一次。自动配置失败时，在 LSPosed 启用修复并只勾选系统桌面后重启。
2. 已包含本次选用的原厂配套应用，包括智慧决策服务、智慧数据增强等；没有外部元模块依赖。不要重复刷原补全包、扩展包，也不要随意覆盖不同版本的系统组件。
3. 流体云真实外卖、打车等场景依赖应用接入、账号、权限与原厂云端，未全部实测，不宣传“完全体”。小布建议卡片、问屏、视频总结、票务日程等完整 AI 功能不在已验证范围。
4. 模块通过开机挂载生效，不永久改写只读系统分区；停用并重启可回退。建议保留可用备份及模块停用方式。
5. 本项目初衷是满足个人设备需求，不承诺维护或后续 Bug 修复，不接受 Bug 反馈。有需要可下载源码自行研究修改，第三方文件遵守各自许可。
