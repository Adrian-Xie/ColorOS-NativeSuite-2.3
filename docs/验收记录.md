# 2.3 公开测试记录

测试设备：OPPO A6k 5G PLT120，ColorOS 15.0.2.1005(CN01)，Android 15，ARM64，4KB 内存页。

## 已有实机记录

- 安装、功能配置、原厂组件与主题资源挂载成功；五个补充 APK 注册成功，附十五个原厂库，已有 OCR / 翻译版本保留。
- 原厂能力接口返回 `is_fluid_cloud_support=true`；这不等于每一种实际订单均正常展示。
- 桌面修复只配置桌面作用域，连续约二十次切换时由用户确认保持堆叠。
- 十一组原厂主题目录已准备并挂载，所有模板与组件选择流程未逐项验收。
- 二十一份 shell 脚本经 Android BusyBox 语法检查；十二组 XML 用例通过条目保留、幂等与参数检查。
- OEM APK 与所提供扩展的哈希一致；修复 APK 由 Android PackageManager 接受。主机 Java 签名复核未完成，不列为通过。
- 交付 ZIP 的 CRC、包内 SHA256 清单核对通过。

## 已知问题与未验证范围

- 另一台 PLT120 / ColorOS 15.0.2.1002 的流体云设置页面退出，未获得足以定位原因的日志，尚无已证实修复。
- 小布建议卡片添加仍返回 `10008`；问屏、视频总结、票务日程未验收。
- 外卖 / 打车等真实订单、全部主题与任意锁屏组件未验收。
- 控制中心亮度 / 音量长按二级面板未完成恢复；未采用音量裁切、亮度触摸 Hook。
- ColorOS 16 与其他机型未实机验证。

公开源码整理没有改变运行时修复逻辑，也不代表再次完成上述全部手机测试。
