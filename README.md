# ColorOS 原生功能整合补全

为部分 OPPO 低端机的 ColorOS 15 恢复原厂流体云声明、堆叠后台、桌面卡片及配套组件。当前版本 **2.3 公开测试版**，由 ChatGPT / Codex 协助编写、调试与打包，属于第三方修改项目。

## 功能与实现

- 按本机原有 XML 修改指定特性，不整份覆盖其他机型的功能表。
- 恢复原厂堆叠后台与桌面卡片，包含仅作用于系统桌面的堆叠状态修复 Hook。
- 补充流体云所需的部分原厂组件，包括智慧决策服务、智慧数据增强等。APK 保留原签名；已有兼容组件不强制降级。
- 包含原厂灵感主题入口及部分补充模板资源，交由原厂编辑器使用；所有模板与锁屏组件尚未逐项验证。
- 不额外开启全局高负载动画和模糊开关；保留系统原有的无关动画配置。未进行量化性能或耗电对比。

模块采用开机挂载，**不会永久写入只读系统分区**。普通后台清理不会撤销模块挂载。停用并重启可撤销配置和资源挂载。

**没有“满血 AI”或所有流体云场景均可用的承诺。** 小布建议卡片仍可能添加失败；一键问屏、视频总结、票务日程和真实外卖 / 打车订单未完成验收。部分小布轻量模式声明有调整，但不等于收到原厂云端功能配置。

## 安装

1. 使用 KernelSU / KernelSU Next 管理器安装发布的整合 ZIP，勿与其他功能补全包或原应用扩展重复启用。
2. 重启。整合包会在缺失时安装固定版本 Zygisk Next 1.5.3、LSPosed Irena 2.0.0；已有框架保留。
3. 点模块的 Action 查看状态。首次安装框架时，自动配置完成后可能还需再重启一次，**同一 ZIP 只需刷一次**。
4. 如果 Hook 未就绪，在 LSPosed 启用“ColorOS 堆叠稳定修复”，作用域只选系统桌面 `com.android.launcher`，再重启。

整合包无外部“元模块”依赖。首次部署包含框架与桌面 Hook，会增加一定启动和内存负担，本机尚未量化。原厂服务的协议、账号、权限和业务绑定需本人完成。

流体云配套组件已包含在整合包内。遇到设置页面退出，应检查组件注册、版本与日志，**不要将随意安装同名 APK 当作已验证的修复**。

## 回退

在 Root 管理器停用整合模块并重启。卸载整合模块会移除配套修复 APK；共享的 Zygisk / LSPosed 框架保留。此前单独安装的旧配套模块可能已被整合包停用，需要时自行恢复。

- `work/public_v2/recents_repair/`：桌面修复 Hook 的 Java、Manifest 与作用域资源。
- `work/suite_research/`：框架作用域配置与原厂主题目录处理辅助源码。
