# ColorOS 原生功能整合补全

为部分 OPPO 低端机的 ColorOS 15 恢复原厂流体云声明、堆叠后台、桌面卡片及配套组件。当前版本 **2.3 正式版**。本项目由作者在 ChatGPT / OpenAI Codex 协助下开发，属于第三方修改项目。

## 功能与实现

- 按本机原有 XML 修改指定特性，不整份覆盖其他机型的功能表。
- 恢复原厂堆叠后台与桌面卡片，包含仅作用于系统桌面的堆叠状态修复 Hook。
- 补充部分流体云原厂组件，包括智慧决策服务、智慧数据增强等。APK 保留原签名；已有兼容组件不强制降级。
- 包含原厂灵感主题入口及部分补充模板资源，由原厂编辑器使用。
- 不额外开启全局高负载动画和模糊开关，保留系统原有的无关动画配置。

模块通过开机挂载生效，不永久写入只读系统分区。普通后台清理不会撤销模块挂载；停用并重启可回退。

## 适用范围与已知问题

主要面向 OPPO A6k 5G（PLT120）、ColorOS 15。PLT120 / ColorOS 15.0.2.1002 存在流体云设置页面退出反馈，原因未定位。ColorOS 16 与其他机型不保证兼容。

不设置固定机型、固件号或 ColorOS 版本上限。仍保留文件完整性、XML、ARM64、4KB 内存页、组件最低 SDK 与挂载条件检查。

小布建议卡片添加问题仍存在；一键问屏、视频总结、票务日程、全部主题与锁屏组件不作功能保证。外卖 / 打车等流体云场景依赖应用接入、账号、权限及原厂云端。配套组件不等于所有云端功能均已解锁。

## 下载

刷机用 ZIP 与 SHA256 位于 [2.3 正式版发布页](https://github.com/yifengxie0-ai/ColorOS-NativeSuite-2.3/releases/tag/v2.3)。安装选择 `ColorOS_NativeSuite_2.3.zip`；GitHub 的 “Source code” ZIP 是源码，不能直接刷入。

## 安装

1. 使用 KernelSU / KernelSU Next 安装整合 ZIP，勿与其他补全包或原应用扩展重复启用。
2. 重启。整合包会在缺失时安装 Zygisk Next 1.5.3、LSPosed Irena 2.0.0；已有框架保留。
3. 点模块 Action 查看状态。首次部署框架后可能还需再重启一次，同一 ZIP 只需刷一次。
4. 如果 Hook 未就绪，在 LSPosed 启用“ColorOS 堆叠稳定修复”，作用域只选系统桌面 `com.android.launcher`，再重启。

没有外部元模块依赖。框架与 Hook 会增加一定启动和内存负担。原厂服务的协议、账号、权限及绑定需本人完成。

流体云配套组件已包含。遇到页面退出应检查组件注册、版本与日志，勿随意覆盖不同版本的系统组件。

## 回退

在 Root 管理器停用整合模块并重启。卸载整合模块会移除配套修复 APK；共享的 Zygisk / LSPosed 框架保留。原先单独安装的旧配套模块可能已被停用，需要时自行恢复。

## 源码与构建

- `work/public_v2/recents_repair/`：桌面修复 Hook 的 Java、Manifest 与作用域资源。
- `work/suite_research/`：框架作用域配置与原厂主题目录处理辅助源码。
- `work/public_v2/`：各部分 shell 脚本、特性补丁与组件来源清单。
- `work/coloros_native_suite/`：当前发布包对应的安装、启动、卸载脚本快照。
- `work/build_*.py`：构建与打包脚本，使用构建者自备签名。

仓库未包含 OEM APK / 库 / 图片、框架 ZIP、SDK、工具链、签名私钥或设备诊断数据，不能下载后直接一键构建。详见 [构建说明](docs/BUILDING.md) 和 [第三方来源](THIRD_PARTY_NOTICES.md)。
